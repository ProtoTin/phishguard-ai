# Security Policy

## Supported version

Security fixes are applied to the latest commit on the `main` branch. This remains an
educational portfolio project and is not approved as a production security control.

## Reporting a vulnerability

Use a private GitHub security advisory when available. Do not publish exploitable
details, credentials, private messages, or active malicious URLs in a public issue.

Include a minimal reproduction using synthetic data, the affected component, the
expected impact, and any suggested mitigation. Maintainers will acknowledge a report
when it is reviewed and will coordinate disclosure after a fix is available.

## Responsible testing

Do not test against systems you do not own or have permission to assess. Do not submit
credentials, trigger downloads, crawl targets, or attempt to bypass network controls.
PhishGuard analyzes provided text and does not grant authorization to interact with a
third-party website.
